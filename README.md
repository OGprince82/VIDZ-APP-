# VidzAI - AI Video Generator

VidzAI is an AI-powered video generation app.

## Features
- Create videos from text prompts.
- Choose vertical, landscape, or square format.
- Select video duration.
- Preview generated videos.

## Technology
- HTML, CSS, and JavaScript
- Vercel for deployment
- Runway API for AI video generation

## Setup
Add your RUNWAYML_API_SECRET environment variable in Vercel.

Never publish your API key in this repository.
